What I learned today: Server-side validation of file uploads must rely on inspecting actual binary magic bytes in the buffer, not spoofable client-provided MIME headers or extensions. Strict privacy requirements like hidden profiles require enforcement at both the API query level and the DB policy level so directories never leak member records. Using controlled forms with unique key resets cleanly prevents stale state and effect synchronization issues.
