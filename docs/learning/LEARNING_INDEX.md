# Learning index

Everyone can read these. Every task gets a learning file.

File name: `docs/learning/R2_backend/build-sessions/D03_R2_admin-api.md` (day number, role, topic). Use `_TEMPLATE.md`. See `_EXAMPLE.md`.

A learning file is complete when another teammate can: explain the feature, follow one request from the screen to the database and back, run the tests, name what can fail, and make a small safe change.

After every merge, add one row to the learning index of your own role, not to this file. Each role edits only its own index, so pull requests from different roles do not conflict.
